# 更难的 PDE 积分识别验证

本轮保留生产基线及上一轮63配置实验，使用独立工作树/分支 experiment/l1-challenge。原 l1_study/engine.py 与 pde_discovery 下的算法不改；只增加新的数据、扰动、验证协议与审计。

固定90配置：3个方程族 × 2采样 × 5噪声条件 × 3方法。仅用积分回归，不提供精确导数，不引入新滤波、噪声补偿或按参考项筛选。plain、一次adaptive、5轮IRL1使用上一轮已固定参数。每个条件内三方法共用全部训练/开发观测；本轮不再进行单/多轨迹数量消融。

## 数据

1. 新公开Allen–Cahn：maziarraissi/PINNs固定提交932f50a2d8ef4e80d1456bbae6887a73ff5166ef的AC.mat，作者方程u_t=0.0001u_xx+5u−5u³、周期边界。原512空间点无重复右端，201帧按120/40/41分训练/开发/最终；机械MAT解码时完整数组进入准备内存，不声称最终场从未解码。模型选择不能读取最终角色。来源细节与MIT说明在source/。
2. 新独立生成低黏度Burgers：u_t=0.03u_xx−u*u_x。更陡的梯度使导数与空间分辨率更困难。
3. 新独立生成KS：u_t=−u_xx−u_xxxx−u*u_x。测试非线性不稳定与四阶耗散；未验证具体轨迹的混沌性质。

两类独立模拟均使用与待测预测器分开的64点轮廓ETDRK4实现。校准初值用加倍空间网格、减半时间步长复核；相对L2≤1e−5且最大绝对差≤1e−4才进入实验。失败不换容易轨迹。每族3训练初值、2开发初值；全部90模型冻结后才生成2个最终初值。这里只是数值基准与人为加噪，不是真实仪器测量。

## 扰动与隔离

先划分角色。完整采样保留角色内全部点；粗采样在空间和该角色时间各取::2，不插值。噪声条件为无噪一次、0.1%和1%各两个种子17/29；百分比相对于完整干净训练轨迹的等轨迹RMS。该尺度只供预定扰动层使用，prepare后冻结，开发/最终不重新估计。

噪声在完整角色网格生成后采样，因此完整/粗采样为嵌套配对观测；不同角色/轨迹/种子的随机流分离。两种噪声水平共享标准正态实现以便配对。每个初始帧也加噪：开发从带噪首帧推进并只对带噪未来选模，最终同样从带噪首帧推进。干净未来只用于冻结后的预测评分，同时另报相对带噪观测的误差。未来首帧是预测输入，初始帧不计分。

选模仍用开发RMSE最优1.05倍加1e−12范围内最少项，再按误差/固定ID；不扣噪声方差，不在看到最终成绩后修改阈值。参考系数只用于最终结构/系数评分，所有失败和额外项保留。完整性检查覆盖90个唯一身份、噪声条件/种子、角色计数、同族训练噪声尺度、文件哈希以及所有工作进程依赖的一致性。

## 指标与候选门槛

主指标为精确项集、漏项、多余项、系数向量误差和逐真实项误差。Allen–Cahn的小扩散项必须单列，不能被±5反应项掩盖。预测误差为辅助，按每配置计划最终轨迹均值汇总；逐轨迹结果也保留，生成或求解失败保留计划分母。

预先选择一次adaptive为晋级候选。门槛见protocol.json：至少2个新增精确恢复且跨至少2个方程族；干净条件不能从成功退化；多余项总量至少降25%，漏项/推进失败不增加；限制每配置系数和预测退化，干净条件每个真实系数误差≤10%。需全部来源质量和回归通过。失败则继续基线、不合并；通过也只是供审查的候选。此为工程门槛，不是显著性检验。90配置共享3个方程族和源场，不能当90次独立物理实验。

## 运行与复现

在项目根目录安装requirements-repro.txt后运行测试。交付中的报告可直接阅读；复现已评分记录不产生新的未见测试。

```bash
python -m unittest discover -s tests -v
python -m challenge_study.run prepare
python -m challenge_study.run freeze --workers 3 --output challenge_study/results/reproduction
python -m challenge_study.run evaluate --output challenge_study/results/reproduction
```

prepare前需有与源码哈希匹配的独立校准收据data/calibration.json，交付说明提供恢复或重新核验命令。prepare会通过固定版本下载器取得AC.mat；不运行作者代码。已存在的prepare/freeze/evaluate产物不覆盖，应保留首轮记录后使用新结果目录。代码/协议改变必须新建一轮，不能沿用冻结结果冒称新证据。
