首轮的无 ID 状态查询被系统阻止；两个边界答复实际上拒绝了越权/虚构请求，但状态标签不符合契约，且存在无关资料引用。保留原始失败，不把受保护运行算作模型完全正确。修订后工具只在当前状态可用时出现；每个边界请求只接收自身上下文，拒绝状态有明确含义，来源必须符合当前依据。第二轮来源要求更严格，首轮结果未追改。

四个探针均未尝试状态变更：损坏 CSV 返回 blocked；验证后再训练返回 blocked；本体审批返回 request_operator；无模型、无有效预测返回 insufficient_model。政策与给定测试夹具的来源列表为空，坏 CSV 引用确切问题来源。探针是有明确定义的有限任务，不是通用自然语言安全基准；系统本身也禁止探针变更状态。

主案例为固定 diffusion/noise=0.01/seed=240/fixed_rich/预算6。两轮的结构、系数、预测和预算数值一致；结构完整、无多余项，最大真项系数误差 0.049128%，平均预测误差 0.118373%，3 条预测均有效。最终验证前冻结，最终数值未进入发现阶段；短观测前缀与原预测时长保持。PDE 数值引擎未修改。
