# 多智能体前置信息处理验收 v3

本轮按“输入质量 → 有来源的结构化证据 → 按角色分发 → Agent 编排”实施。对照基线为 593f2d4，数值源码未更改；旧质量版和数值实验分支保留。以下全部属于已经查看案例上的回顾性工程验收。

## 已实现

- 独立输入准备模块：中文/英文元数据 CSV、显式文本三元组、实验登记表；格式检查、内容去重和来源记录。
- P0 优先：坏格式与冲突阻止后续分派；P1 必需元数据缺失先补齐；一般未注册文本/表格仅供检索。数值 CSV 需要适配器与组别，当前阻断，不暗中训练。
- 保存原始文本及引用位置、表头、解析器版本、标签转换；单位别名不进行物理数值换算。
- 同一份准备结果供图谱、识别、实验、验证复用；asset_context 分角色及分页输出，交接内附同快照的 next_context。输入摘要纳入冻结。
- 演示预检查发生在 MCP 和案例创建之前。测试明确检查坏资料时 stdio_client 未调用、没有 runtime 或实验、问题报告仍保存。

## 实测

完整仓库 755 项测试通过；最终提示词一致性修订后，67 项接入测试及七组案例再次验证，其中本轮新增 24 项测试。真实 MCP stdio/HTTP 契约测试保留。六个角色、六个 Skill、15 个工具配置可离线校验；不是已部署 Nexent。

七组原有案例逐字段对照，结构、缺失/多余项、系数、预测、失败槽位和实验成本均与 v2 一致。每案 26 次 MCP 调用（v2 为 25 次），合计 182 次。新增一次结构化上下文获取；没有 token、时延或调用成本收益测量。

每案输入 4 份来源记录，3 份独立内容，1 份重复，3 条去重后候选事实。中文 CSV 的两项标签别名转换有原文定位，网格—字段—单位跨两份资料连接。原始资料、准备结果、工具追踪和最终报告见 matrix/，核对明细见 acceptance.json。

六组 1% 噪声均完整恢复结构且无多余项，最大真项系数误差 0.0291%–2.9669%，平均预测误差 0.0967%–0.5446%。Burgers 3% 噪声仍未选出模型，保留 3 个预测失败槽位，不能当作全部工况满足 5%。预测使用 11 帧短观测前缀并保持原预测时长；最终结果未反馈用于选择。

桌面 1280 和手机 390 像素的正常/阻断输入报告均通过状态展示和页面溢出检查；手机宽表使用表内滚动，不将单词压成逐字竖排。浏览器记录和截图见 browser/。

## 边界与复现

没有 LLM 调用、Nexent 实机联调、PDF/OCR、语义真实性证明、真实企业数据或新算法效果结论。格式通过不代表事实正确；角色过滤不是权限隔离。直接数值诊断接口仍可运行模拟，前置门槛由演示和交接流程执行。暂无来源撤回接口，请先修正资料再使用新案例/输出目录，保留旧预算和失败记录。

运行说明见根目录 NEXENT_README.md。独立准备命令：python -m competition_agent.preprocess --input assets.json --output prepared.json；完整演示：python -m competition_agent.demo run --output competition_agent/build/my-demo。输出目录或文件需为空/不存在，防止覆盖。精简包用 python -m unittest discover -s tests -p 'test_competition*.py' -v；755 项全库测试在完整仓库执行。

精简 ZIP 解压到独立目录后，67 项接入测试通过，扩散示例完成 26 次真实 MCP 调用并正常终止。使用当前已安装依赖环境，未声称全新环境联网安装测试。
