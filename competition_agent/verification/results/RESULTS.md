# 本地 MCP 集成实测

确定性脚本调用真实 MCP，无 LLM；回顾性合成工程演示，不能据此推断新算法收益、真实行业效果或多智能体推理质量。固定预算7次、seed240、保留 fixed_rich 基线。最终评估成本另列。

| 案例 | 结构完整 | 多余项 | 最大真项系数误差 | 三条平均预测误差 | 预测失败槽位 |
|---|---:|---:|---:|---:|---:|
| decay-noise1 | 是 | 0 | 0.1420% | 0.0967% | 0/3 |
| diffusion-noise1 | 是 | 0 | 0.0291% | 0.1235% | 0/3 |
| hyperdiffusion-noise1 | 是 | 0 | 0.2122% | 0.1336% | 0/3 |
| advection_diffusion-noise1 | 是 | 0 | 0.1613% | 0.1285% | 0/3 |
| reaction_diffusion-noise1 | 是 | 0 | 0.0330% | 0.1146% | 0/3 |
| burgers-noise1 | 是 | 0 | 2.9669% | 0.5446% | 0/3 |
| burgers-noise3 | 否 | 0 | 100.0000% | 无模型，未预测 | 3/3 |

六个1%噪声案例完整恢复结构，最大真项系数误差0.0291%–2.9669%，平均预测误差0.0967%–0.5446%。3%噪声Burgers未选出模型，缺失两项，按协议保留3个失败槽位，真项误差按100%计；没有为了出结果放宽判据。

共105次成功的MCP业务调用；其中返回“无模型”的调用在协议层成功，在数值任务层失败。另有实际协议错误路径测试。每案7次发现实验，每次7104个标量；六个成功案例另各生成3条最终参考轨迹，高噪声无模型案例保留评估槽位而不生成最终轨迹。

plan.json 固定了案例列表与源码哈希。每案报告、完整MCP参数/返回及事件链均保留在相邻目录。原始观测NPZ位于交付包中的 demonstration-runtime 目录；可用同一命令重演，但已查看条件不得再称盲测。
