# 独立实验分支：解析导数、多轨迹与重加权 L1 对照报告

本轮在独立副本中完成 **63 个预声明模型配置** 的训练、开发选模、冻结和最终评分。旧 Burgers、KdV、KS 三组的精确项集合恢复由普通 L1 的 **0/3** 提升到自适应 L1 和 IRL1 的 **3/3**，多余项总数由 4 降为 0；但这是对已经查看过最终数据的**回顾性比较**。新增无噪声解析轨迹中，两种重加权方法也在数值导数输入下提高结构恢复；没有发现 IRL1 相对一次自适应 L1 的明确额外收益，也没有发现多轨迹相对单轨迹的结构恢复数量收益。

预设数值门槛已通过，165 项回归测试通过。本轮决定是**认可重加权相对基线的收益，保留独立候选分支，不合入原项目**。原因是预定候选五轮 IRL1 相对一次 adaptive 在全部21对配置上的支持、系数与预测完全一致，没有额外收益；新解析积分主路径的普通 L1 已全部恢复，独立结构改善集中在点态数值导数变体，因此不直接把这份复杂度引入默认引擎。结果文件的状态仍为 `eligible_for_review_only`，不能说成门槛失败；门槛本身不是统计显著性检验。

## 先修正参考导数，再冻结实验

参考 `redo_two.py:84` 的高斯三阶导数确有错误。令 `s=σ0²+2νt`、`ξ=x−x0−ct`，正确式为：

```text
u_xxx = u * (3*xi/s**2 - xi**3/s**3)
```

旧式展开为 `u*(5*xi/s**2−3*xi**3/s**3)`。只核验对流扩散真方程 `u_t+c*u_x−ν*u_xx=0` 发现不了这个错误，因为真方程没有用到三阶干扰列。修正补丁及审查在 [reference_review](reference_review/REVIEW.md)，修正和独立核验均在实验源码冻结之前完成。

自写 [gaussian_check.py](gaussian_check.py) 用两种宽度、合计 400 点复步长微分检查 `d(u_xx)/dx`：修正式最大绝对误差 `2.6645352591e-15`，旧式最大绝对误差 `9.8404458510`。另外有 Hermite 非中心零点回归测试。运行 `python -m l1_study.gaussian_check` 可复现；这个检查不是 PDE 恢复成功率。完整第三方源码因无明确许可不随交付复制。

## 方法与公平比较

参考仓库可借鉴的是一次岭回归生成权重的 **adaptive L1**、多轨迹共享系数、解析导数核验及支持内最小二乘去偏。固定 5 轮 **IRL1 是本分支新增实验**，不是参考仓库原有实现。

三方法共用训练 RMS 归一化、十点 alpha 路径、支持阈值与支持内 OLS 去偏。岭 pilot 在归一化训练矩阵上使用 `1e-6` 正则；权重为 `clip(1/(abs(beta)+1e-3), 1e-2, 1e3)`。adaptive 每个 alpha 解一次，IRL1 每个 alpha 独立从同一个训练 pilot 起步并解五轮。参数、阈值、候选身份、评分规则与唯一晋级候选 IRL1 均事先写入 [protocol.json](protocol.json) 并冻结。

开发阶段使用所有开发轨迹 MSE 等权平均的平方根，在最优 RMSE 的 `1.05` 倍加 `1e-12` 容差内优先选最少项，再按误差和固定候选 ID 决胜。**没有跨 alpha 比较带惩罚目标，没有 lambda 路径频次投票，没有参考支持或最终误差参与选模。**跨 lambda 的惩罚目标不是同一个风险函数，路径频次也不是独立数据重采样稳定性。参考仓库真值附近初始点没有借用。

主要指标为精确支持、漏项、多余项和包含额外项的系数向量相对 L2；预测是辅助指标。下列系数误差为 `||估计−参考||₂/||参考||₂×100%`，依赖坐标和变量尺度，不跨物理单位合成准确率。原阈值在训练阶段执行；所有保留项均参与最终评分。

## 新解析初值：多轨迹与导数消融

三个解析族为对流扩散、线性二至四阶方程、Cole–Hopf Burgers。每族预先固定 3 条训练初值、2 条开发初值、2 条最终初值；空间 64 点、时间 81 帧、无噪声，初值都含四个模式。不同角色不是同一条轨迹的切片。所有场由解析公式生成，不调用待验证的发现或预测引擎，也不是真实测量。生成器当然知道预定方程，不能称完全未知物理盲发现。

比较 3 种表示 × 1/3 条训练轨迹 × 3 种方法 × 3 个方程族，共 54 个模型。单/多轨迹在每种表示内采用相同总回归行预算与固定抽样规则、等轨迹权重，避免把增加行数当成联合识别优势。不同表示的预算可能不同。

全部 63 个模型及元数据通过全局冻结检查后，才生成新最终初值场并读取最终评分参考；旧公开数据最终角色也不进入本轮训练选模。新最终预测每个模型有两条独立初值，表中辅助预测值为这两条相对 L2 的均值。

可支持的判断是：

- **重加权在数值导数输入下改善结构。** 普通 L1 在单轨迹和三轨迹下都只有对流扩散精确恢复，线性高阶各多 3 项、Cole–Hopf Burgers 各多 2 项。adaptive/IRL1 将这四个配置都恢复为精确支持。它们是四个配置改善，不是四项独立物理实验。非 oracle 的12个配置中，普通 L1 为8/12，重加权为12/12。
- **本轮未显示多轨迹的结构数量收益。** 对每种输入与方法，单轨迹和三轨迹的精确支持数量及多余项总数完全相同，但某些多余项的身份发生变化，不能说两套模型完全相同。部分系数改善、部分变差，例如积分 Cole–Hopf 的普通 L1 系数误差从 `6.4163e-8%` 增至 `8.3939e-6%`，仍很小，但不能宣称联合识别全面更好。所有初值已经充分含四个模式，本轮没有专门制造单模态别名来提高多轨迹收益。
- **精确导数只提供受限 oracle 对照。** 普通 L1 从数值导数每组1/3到解析导数3/3，系数误差接近浮点精度。但解析模式同时去掉数值求导误差和谱投影差异；Cole–Hopf 场不严格带限，不能把收益全归因于时间求导。精确输入是解析信息下的对照上限，不是可部署的测量输入或严格理论性能界。精确系数下仍有有限推进误差，说明系数恢复与预测误差来源不同。
- **没有 IRL1 优于 adaptive 的明确收益。** 两者在21对对应配置上的支持、去偏系数、系数评分和最终预测完全一致，没有可主张的额外收益。IRL1 每个 alpha 多次求解，不能据此声称它优于更简单的一次自适应权重。事先指定 IRL1 为晋级候选，没有在最终评分后偷换为成绩看起来更好的方法。

## 工程门槛、回归与合入状态

[comparison.json](results/first_run/comparison.json) 的 `numerical_gate_passed=true`：公开三组至少2组精确恢复、总多余项不超过2；非 oracle 配置无结构成功倒退、无新增漏项或预测失败；逐例系数误差不超过 `max(1.10×plain,1e-4)`，逐例预测误差不超过 `max(1.25×plain,1e-3)`；新解析非 oracle 至少一例结构严格改善。这些容忍度使用比值而非百分数，均在评分前冻结。

最终日志 [l1-study-final-tests.log](../artifacts/l1-study-final-tests.log) 为 **165 项通过**，其中包含原128项与新增37项，不能另加成293。测试覆盖权重优化、联合尺度/预算、解析导数、负二阶稳定化、完整63身份冻结、最终数组隔离、参考信息不影响发现、篡改与失败路径等；不是用程序测试数量代替实验收益。

当前保留原目录为活动基线，实验独立保存，**本轮不合入生产目录**。数值门槛与回归检查均通过，认可加权 L1 相对基线的改善；但预定五轮 IRL1 与一次 adaptive 的21组成对支持、系数及预测完全一致，没有额外收益，因此不将额外复杂度直接引入默认引擎。另一个保留理由是新解析积分主路径的普通 L1 在单/多轨迹下均已3/3，独立新结构收益集中在点态数值导数变体。这个决定不是门槛失败，也没有依据当前最终结果把 adaptive 偷换成已批准候选或宣布合入。下一轮可优先将一次 adaptive 预先声明为候选再验证，尚未实施。已有公开基准证据仍是回顾性的，新初值只覆盖三个无噪声解析族；真实测量、高噪声与更广泛方程尚未验证。
