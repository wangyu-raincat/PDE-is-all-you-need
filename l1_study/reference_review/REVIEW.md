## 已修正的导数错误

`redo_two.py:78–87` 定义扩散并平移的高斯：

```
s = sigma0**2 + 2*nu*t
xi = x - x0 - c*t
u = exp(-xi**2/(2*s)) / sqrt(2*pi*s)
u_xx = u*(xi**2/s**2 - 1/s)
```

固定 t 后 s 与 x 无关，故

```
u_xxx = u_x*(xi**2/s**2 - 1/s) + u*(2*xi/s**2)
       = u*(3*xi/s**2 - xi**3/s**3).
```

原第84行实际等于 `u*(5*xi/s**2 - 3*xi**3/s**3)`，不是正确三阶导数。差值为 `2*u*xi*(s-xi**2)/s**3`。作者在108–126行检查 `u_t+c*u_x-nu*u_xx`，没有使用 `u_xxx`，因此真 PDE 残差检查不能发现库中的这条错误干扰列。

本地 `corrected/redo_two.py` 只改此行；原文件保持在 `original/redo_two.py`。可审核补丁为 `redo_two_gaussian_third_derivative.patch`。原文件 SHA-256 `0923afdf5a4e73f6461c9b3da60e7f97c96f0af2fd677a7e9df2d86ba4df6ab7`；修正文件 SHA-256 `82d5c039b9e23402159e95df0278c4ef50b5d1d6c76386161f5be4a6aea76203`。

验证包括独立 SymPy 三次求导与二阶导数的复步长微分。固定种子20261028、sigma0=0.5/0.9、各200个点，修正公式最大绝对误差分别为 `2.6645e-15`、`2.2204e-16`；旧公式分别为 `9.84045`、`0.97350`。详见 `gaussian_derivative_verification.json`。这只是导数单元验证，不是 PDE 恢复实验结果。

## 可借鉴内容

1. **多轨迹联合系数。** `inverse_burgers.py:73–96` 纵向拼接不同波速的行波设计矩阵。单条波精确满足 `u_t=-c*u_x`，会产生比 Burgers 更短的别名；不同速度可排除共同的单一平流系数。`redo_two.py:104–115` 对不同初始高斯宽度按各轨迹目标范数平衡后联合。应在当前项目中使用训练轨迹自己的尺度，明示每条轨迹权重，并检查共享物理参数；不能把不同参数轨迹随意拼接。
2. **精确导数对照。** `redo_two.py` 高斯、KdV tau 函数导数和 `inverse_burgers.py` 行波导数可启发“导数估计误差 vs 稀疏优化误差”的消融。每一候选列都需独立校验，不能只检验真 PDE 残差。解析导数是人工构造的 oracle 对照；在实测数据中通常不可用，不应当宣称提高了真实传感器数据恢复能力。
3. **自适应 L1。** `redo_two.py:50–57` 与 `inverse_burgers.py:168–192` 用岭回归计算一次 `w_j=1/(|beta_ridge_j|+eps)^gamma`，再加权 L1。可以独立实现并与普通 L1 作配对比较。所有列尺度、初始岭正则、eps、gamma 只能由训练与开发协议决定。
4. **支持内去偏。** 保留候选支持后以训练数据最小二乘重估系数，减少 L1 收缩偏差；系数重估与支持生成分开报告，不能看真值后删小项。

仓库的权重主要是**一次自适应权重**，并没有迭代更新重加权规则。当前项目若实施 IRL1，应明确标为新增加的实验方法，而不是声称直接复现该仓库已有 IRL1。

## 明确不沿用的规则

- **跨 lambda 比较带惩罚目标。** `optimize_ux.py:39,64` 计算 `SSE+lambda*sum(w*abs(beta))`，再跨 lambda 取最小值。不同 lambda 定义不同函数，数值不可当作同一验证风险比较；最优带惩罚目标随 lambda 下降天然趋于降低，因此可能把选模退化为偏好最小惩罚。另有常数因子问题：其坐标下降阈值 `lambda*w` 对应 `0.5*SSE+lambda*L1`，记录的 SSE 目标并不是完全一致的优化目标。
- **路径频次过半。** `redo_two.py:55–59`、`inverse_burgers.py:195–215` 的频次取决于 lambda 的范围、网格密度和阈值，同一训练样本在不同惩罚下不是独立重采样；这不能解释为统计稳定选择概率。可以保存路径诊断，但不用于最终支持投票。
- **真值初始点。** `tier3_kdv.py:305,329` 使用真项系数的0.9倍启动。作者已披露它不是盲搜；本项目发现阶段不得采用。
- **改变支持门槛追求成功。** `optimize_ux.py:15–16,66–68` 将计数1e-5与删项1e-3分开。阈值如要比较必须预先冻结，不能依据已查看最终答案选阈值。

## 实验隔离建议

比较普通 L1、自适应 L1 和固定轮数 IRL1；相同训练轨迹、库、归一化、去偏和开发规则下配对比较。多轨迹与精确导数作清楚的消融，不将同时改变多项的收益归因于单一方法。开发集按统一误差/复杂度或预定噪声容忍规则选模，参考支持只在最终评分中使用。主要报告严格支持恢复、漏项、多余项、包含多余项的系数误差；未来预测只作辅助。对旧 Burgers/KdV/KS 三段结果的再比较属于回顾性；新合成独立初值只证明合成范围，不能称新真实实验。所有预声明案例与失败都必须保留。
