# 融合回顾性实验独立复核

复核范围仅为 `development/retrospective/` 的冻结 JSON、模型 JSON，以及上一轮 resolved 实验的冻结模型、结果 JSON 和参考方程 JSON。未读取任何 NPZ 原始场数组，未重新拟合、推进、生成初值或运行新的最终评分。此处的旧数据已经查看，全部结果只能作为回顾性分析。

## 复核结论

60 个新组合模型的文件摘要全部匹配；60 条缓存对照与旧 comparison 原记录完全一致。120 条结构和系数指标、360 条已保存逐轨迹指标的聚合均可从记录重建，没有发现矛盾。预测复核只重算已保存逐轨迹指标的平均和汇总，没有从原始场独立重算误差，不能据此声称重新验证了求解器。

旧实验上的融合恢复了完整项集，并降低此前的弱扩散系数误差；其预测中位数略升，最坏条件预测误差不变。因此这不是所有指标同时改善的结果，更不能替代冻结后的新数据验证。

## 融合贡献与具体旧失败条件

| 方程族的最坏真实项系数误差 | weak_original | weak_resolved | anchored_best | fused_median |
|---|---:|---:|---:|---:|
| Allen–Cahn | 37.2935% | 37.2935% | 37.2935% | 15.7373% |
| Burgers | 0.850535% | 0.850535% | 0.850535% | 0.850535% |
| KS | 9.712358% | 0.657880% | 0.657880% | 0.657880% |

AC coarse、1% 噪声、种子 89 的扩散项，原两臂和 anchored_best 均为 `1.3729348249e−4`；fused_median 为 `1.1573734574e−4`，对应误差从 37.2935% 降至 15.7373%，绝对下降 21.5561 个百分点、相对下降 57.8014%。这个改善来自系数融合，单独锁定支持的 anchored_best 没有修复它。然而该条件的预测误差从 anchored_best 的 2.14183% 略升至融合的 2.17204%，再次说明预测最优与小系数准确并非同一目标。

AC full、1% 噪声、种子 89 中，weak_resolved 多出的 `u_xxxx` 来自跨结构选模。anchored_best 与 fused_median 都继承原弱形式的三项结构，均没有此多余项。其扩散系数分别为 `1.0488855040e−4` 与 `1.0424996354e−4`；这里结构改善应归于原结构锚，不能全部归于中位数。

融合接受情况为 **21 个接受中位数、9 个仅有一个近优变体而保留 anchored_best**。21 个接受条件中，17 个池包含三个变体，4 个池包含两个变体。没有中位数预测拒绝、超阈值拒绝或无效系数拒绝。接受不等于系数一定改变：相对 anchored_best，实际有 15 个条件的系数向量改变；其中 11 个条件的记录预测误差上升。多数小幅预测变化受到开发期近优容差约束，但不能从“接受”推断最终逐条件预测都更好。

## 模型与选择证据检查

逐一完成以下检查，没有调用拟合或预测函数：

- 冻结索引恰好包含 60 个唯一新组合模型，结果恰好包含 120 个唯一配置；全部模型的 SHA-256 与索引相等。
- 每个新组合模型引用的原 weak_original、weak_resolved 文件摘要，与旧冻结索引和实际旧 JSON 文件均相等。缓存 60 条完整结果与旧 comparison 逐字段相等。
- 每个组合模型的结构锚和候选 ID 等于原结构选择；最终系数项集与锚严格一致，没有事后加项、删项或跨结构平均。
- 同结构候选恰好来自旧加密评分中拟合成功且开发合格的候选；最佳候选按开发误差和固定 ID 排序得到。近优阈值严格等于 `1.05×best+1e−12`。
- 每个变体的代表按固定候选 ID 去重后进入近优筛选，池成员与记录完全一致，不按 λ 数量或候选出现次数加权。
- 所有提出的中位数都能由保存的成员系数逐项重算；接受条件的两条开发轨迹 RMSE 按等轨迹方式重聚合后，与记录和接纳阈值一致。仅一变体的 9 条配置确实保留 anchored_best。
- 120 条记录的完整项集、多余项、漏项、系数向量相对 L2 和逐真实项相对误差，独立用项名字典和参考 JSON 重算后吻合。
- 每条结果保留 3 条成功推进指标；条件平均与四臂全部汇总能从已保存指标重算。没有省略失败配置或只展示有利条件。
