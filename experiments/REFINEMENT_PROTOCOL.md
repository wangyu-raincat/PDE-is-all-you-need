# 实测热杆改进方法：预先固定的回顾性比较协议

本协议先于本轮 repeat3 数值读取和结果计算写入。上一轮已经查看过所有九组 repeat3 结果，因此本轮只能称**回顾性方法比较**，不能称首次盲验、新独立测试或无偏泛化估计。保留上一轮 L1 结果，不覆盖原报告。

## 改进及边界

新分支使用物理先验模型 `theta_t = D theta_xx - h theta + c`，其中 `D > 0`、`h >= 0`，比较四种预设支持：仅扩散、扩散与衰减、扩散与常数、扩散与衰减及常数。扩散是先验必选项；四支持比较不是 L1 优化，也不是从任意候选库自动发现物理定律。原 L1 分支继续保留用于对照。

系数直接拟合训练重复实验的四个内部温升轨迹，避免对有噪声的内部实测值直接作空间差分后用作回归特征。空间算子仍为六个原测点的中央差分半离散模型；没有增加空间测量点。预测输入始终只有两端完整实测温升与四内点初始值，不输入后续内部实测温度。边界在原始时刻之间作分段线性输入，不被计作新的测量证据。

数值求解器和优化器的界限、初值、容差由 `real_heat_refined.py` 的固定配置给出，并随每个冻结模型一起归档。各支持均只用 repeat1 拟合，训练不接受开发或 repeat3 输入。正扩散和非负衰减约束不代表所得参数已被认证为材料物性。

## 固定角色和选模

- 九组固定顺序：50ss、75ss、100ss、50al、75al、100al、50cu、75cu、100cu。主要案例仍为 50ss。
- 沿用既有 manifest：完整 repeat1 训练、完整 repeat2 开发选模、完整 repeat3 回顾比较。不能裁剪、换组或移除失败组。
- 每种支持的系数仅拟合 repeat1。拟合失败、局部参数敏感性 Jacobian 秩不足、非有限预测或无效优化候选必须记录并拒绝，不能静默用其他阶段重新拟合。缺少秩诊断也不得进入选模。优化边界命中保留作诊断，不自动拒绝；局部满秩仍不能证明物性或机制唯一。
- 在 repeat2 上计算四内点 RMSE，排除初始帧。开发 RMSE 在最优值 1.05 倍内先选最少项，再选最低开发 RMSE；仍相同则按固定模型标识排序。
- 保留所有近优支持以提示结构歧义。敏感性条件数与训练前后半参数稳定性只作诊断，不能根据 repeat3 调整判据。
- 必须先保存九组冻结模型及其 SHA-256，再执行任意一组 repeat3 回顾评分。单组复现命令也必须先完成该次声明分组的模型冻结，且清楚标记不是九组总验收。
- 冻结文件校验失败即停止对应评分。模型在 repeat3 预测失败时记录失败，禁止重新选模或修改训练参数。

## 评分与解释

本轮汇总逐组同时展示旧方法和新方法：四内点相对 L2、RMSE、支持项数；使用相同原始 CSV 和相同计分行。两种简单基线仍为初值持久值与给定边界的线性空间插值。5% 仅为描述性参考线。

公开全部九组结果和失败信息。不得把低误差、较少项或强制保留的扩散项当作“正确 PDE 已发现”。新分支识别的是物理先验下的粗网格有效模型；传感器误差、模型失配、边界测量噪声和有限空间分辨率均可能改变估计系数。条件预测改善不代表未知未来边界下的自由预测或跨设备泛化改善。

最终物理机制与泛化主张仍需要此前从未用于调参的新实验记录，并应考虑增加测点、独立温度标定与不同激励。此次不新接入平台、不控制实验设备、不改变现有数据许可。
