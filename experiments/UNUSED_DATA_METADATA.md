## 分组与重复关系证据

- [数据论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC8813594/)（DOI `10.1016/j.dib.2021.107632`）第 1 节定义：第一字母是构建方向 x/y，第二字母 p/n 区分较多孔与非较多孔类别，数字是测试序号；该节还说明共有四根增材杆。`n` 不能解释成绝对零孔隙。
- [关联增材原论文的出版社页面](https://www.sciencedirect.com/science/article/abs/pii/S2214860421000518)（DOI `10.1016/j.addma.2021.101886`）的 “Thermal conductivity results” 段明确说明每根杆测试五次并取平均。此次证据来自网页搜索返回的出版社正文片段；随后直接打开页面返回 HTTP 403，未重试。这里只采用重复次数声明，不采用其拟合热导率数值。
- [作者 V1.0.0 分析源码](https://github.com/lbtcn6/oneDkhEstimator/blob/V1.0.0/oneDkhEstimator.py) 第 223–250 行为每种增材杆列出五个固定文件名和一组几何参数，支持上述映射。该源码没有逐次采集日志。

由这三项证据，可将文件识别为同杆的五次重复测试记录；这不是对统计独立性或逐次工况一致性的证明。

- 时间单位为秒：源码第 456 行标注 `Time (s)`。
- 温度为相对环境的温升：数据论文第 1 节及第 2.2 节明确说明 thermocouple columns 是 excess temperature，即温度减环境温度；摄氏温差数值等于 K。不要再次减去环境温度。
- 格式依据作者读取逻辑：逗号分隔、跳过首行、时间在第 0 列、按从近加热端到远端顺序使用第 1–6 列；额外功率列是 10 bit PWM 指令，不能当作瓦特。未读取增材文件表头，因此这是来源规定的预期格式，尚不是逐文件实检结果。
- 第 246 行 `VV=[5,...]` 注释是 `wind speed guess`；第 248 行 `Tinf=20.8` 是代码设定。这些不能替代每次实验的风速/环境实测日志。当前来源未确认增材五次的相同加热设定。
