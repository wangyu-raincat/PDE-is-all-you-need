# 跨方程类型的稀疏 PDE 发现验证协议

目标是从观测场识别微分项和系数，并独立检查预测；不是在预定热方程中校准材料参数。本轮比较作者公开的 Burgers、KdV、Kuramoto–Sivashinsky 三个数值基准，均不是实测实验。来源固定为 snagcliffs/PDE-FIND 提交 `86911349b9fac82996e35465a13d06205730cc05`。算法在这些数据的任何数值解析之前固定；参考方程用于最终计分，不参与拟合、筛项、开发选模或失败补救。候选库的设计已知要覆盖这些类型，本轮不是无任何先验的盲发现。

## 固定范围、数据与划分

只支持一维标量、常系数、均匀空间和时间网格、左侧固定为 u_t 的方程。空间闭合采用周期延拓。Burgers、KS 的同字节公开教学使用明确设置周期；KdV 的作者文档支持谱方法，但未独立核实生成器的边界设置，其周期闭合明确作为本轮数值假设，不能说是已核实物理边界。记录训练段接缝差和相邻空间差的诊断，不按最终误差更换边界或数据。

固定数据组为 burgers、kdv、ks，三个都报告，不能只保留成功者。每个完整源轨迹按原时间行分割：训练 `[0,floor(0.6*N))`，开发 `[floor(0.6*N),floor(0.8*N))`，最终 `[floor(0.8*N),N)`，每段至少16帧。保留全部原空间点与原坐标单位，不空间升采样、降采样、改单位、重排观测值、删时间段、按方程单独调预处理。源坐标不自动解释为米和秒。

MAT 是压缩格式，准备步骤必须机械解码整个数组，再写入互不重叠的三份 NPZ；这一步会解析最终数值，不宣称测试值从未进入内存。准备阶段只做事先规定的格式、形状、有限值和网格校验及分割，不作建模、图表或性能分析。训练和开发函数只读取各自角色文件。所有数值滤波/积分局限在当前训练段，不跨时间分割边界。

来源分析采用实部场。若 MATLAB 数组为复数，仅当虚部最大绝对值不超过 `1e-10*max(1,max(abs(real(u))))` 时按事先固定规则取实部，记录虚部幅度；否则报告数据不适配，不静默丢弃真实复数信息。该容差在实际准备数组之前设定，不根据最终成绩改变。

## 固定发现方法

所有数据使用同一候选库 `[1,u,u^2,u^3,u_x,u_xx,u_xxx,u_xxxx,u*u_x]`；任何一项都不是必选项。统一空间 Fourier 投影保留 `|mode|<=floor(Nx/3)`，报告滤除部分相对 L2 范数（不是平方能量比）；本轮为清洁数值基准，不作时间平滑，不追加人为噪声。高阶导数来自相同空间投影。时间积分采用 Simpson，窗口帧宽 `max(3,min(12,Nt//10))`，起点步长2，并按引擎固定边缘裁剪规则构造回归。引擎源码与 FIT_PROTOCOL 在首次实际训练前冻结；不得按测试结果改变这些配置。

候选列和目标按训练 RMS 缩放。固定 LASSO alpha 路径为 `3e-6,1e-5,3e-5,1e-4,3e-4,1e-3,3e-3,1e-2,3e-2,1e-1`，归一化筛项阈值1e-6，保留支持后最小二乘去偏。保留优化收敛、支持秩、条件数、相关列及失败原因；秩不足或未收敛的候选不参与开发选模。

前向预测使用通用半线性谱 ETDRK4，引擎按真实列出的系数计算所有项；每个原采样间隔固定32个子步，固定总步数上限20000。不将热杆的正扩散限制套用到所有 PDE；二阶负扩散与稳定四阶项可以共存。最高偶阶空间算子的高频不稳定性、数值溢出或预算超限应显式记录，不能静默改写系数。非线性项采用固定谱去混叠。候选生成和前向引擎都不接收数据集名称、方程标签、真值系数或未来场值。

只用开发整段的自由前向预测 RMSE 选模：在最优值1.05倍以内先选最少项，再较低误差，最后稳定候选ID；保留所有近优支持与歧义。各段预测只给原空间坐标、时间坐标和该段首帧，不喂入后续边界或内点场。初始化首帧不计分。

## 冻结与最终评分

三个数据组全部完成训练、开发选模并写出冻结索引后，才能读取最终角色文件或解析参考方程 JSON。冻结记录包含原始 Git blob/文件哈希、三角色数组哈希、来源清单、协议、代码依赖及参考 JSON 的字节哈希。字节散列不用于模型决策。最终阶段先统一校验所有冻结记录，再分别评分；最终数据不重选模型、不更改候选库、不重新拟合系数。失败保留在三组总表中。

主要方程指标：精确支持匹配、支持 precision/recall/F1、统一候选坐标下系数向量相对 L2 误差；缺失项系数按0计，额外项进入误差。只将最终冻结项与独立参考表比较，不为提高得分事后删小项。系数阈值仅为训练阶段固定筛项阈值。

独立报告最终轨迹的 RMSE、相对 L2、初值持久基线及数值积分失败。方程指标和预测指标分列，不用一个替代另一个。KS 等敏感动力学中，即便结构正确，长期相位误差也可能较大；同时，轨迹拟合好不能证明结构唯一。单轨迹时间留出不是新初值、跨装置或实测泛化验证。完成首次评分后后续只能称复现。
