# 独立来源热杆数据：新旧方法比较协议

本协议在读取本轮四份原始数值文件之前固定。来源为 TariqSawaqed1/Heat-Conduction-Aerospace-Lab，固定提交 `aba5a8c3c1d52fb879710cdddcfb23d29b079f03`。这是作者标注为 ASEN 3802 实验的教学资料，非原 Mendeley/ATMC 来源；不能据公开仓库证明独立复测或完整计量溯源。

## 固定数据与划分

- aluminum：`Aluminum_26V_250mA.txt` 的前 `floor(0.6*N)` 行训练，剩余行开发；`Aluminum_28V_269mA.txt` 全部行最终测试。
- brass：`Brass_26V_245mA.txt` 同样按 60/40 划分；`Brass_29V_273mA.txt` 全部行最终测试。
- 钢只有一条条件记录，事先排除，不按表现挑选材料。重复目录和文件副本不算新实验。
- 两组固定顺序 aluminum、brass。仅用原始 CH1 至 CH6，间距 0.0127 m（0.5 in），时间秒、原始温度摄氏度；CH7/8 事先排除，避免改动六点数值引擎。不做空间插值、降采样、平滑、挑段或删异常值。
- 每组统一参考温度 `Tref = mean(训练第一帧 CH1..CH6)`，所有训练、开发和测试使用 `theta=T-Tref`。Tref 不是测得的环境温度；绝不能按测试初值另行归零。时间保持原采样坐标。
- 开发段初始化用开发首帧的四个内点；最终整条高电压测试初始化用其首帧内点。训练/开发是同一采集的时间段，最终是不同电压的另一记录；不宣称不同装置或统计独立重复。公开资料未独立核实精确采集日期和是否同一物理试件。

## 固定方法

新模型原封不动使用 `real_heat_refined.py` 四个物理支持 D、D+h、D+c、D+h+c，方程 `theta_t=D theta_xx-h theta+c`，原参数界限、三个初值、优化容差和求解器不变。仅用训练四内点轨迹拟合；优化成功、局部敏感性满列秩且开发预测有限才合格。开发 RMSE 在最佳 1.05 倍内先最少项，再较小 RMSE，最后模型名。保留所有失败候选、近优结构、边界命中和条件数。新模型属于物理先验校准，不是 L1 自动发现。

旧方法直接复用 `real_experiment.select_model` 与 `real_heat.py`：五项候选库、固定 LASSO 路径、训练时长 2%/5%/10% 且至少两采样间隔的积分窗口、支持集去偏和原开发选择规则。不按最终表现调整旧方法预算或排除不利结果。两种方法各自重新拟合本轮低电压训练数据，不是直接迁移旧材料的系数。

两组两种方法全部写入冻结文件及索引，记录源文件 Git blob SHA-1、下载 SHA-256、方法源码/协议/来源清单哈希后，才允许解析任一高电压测试记录。最终阶段校验冻结索引和依赖；禁止重新拟合或重选模型。下载或校验原始字节不等于读取数值。失败单独记录，仍保留两组和两方法完整结果。

## 指标与主张

所有预测只接收 CH1/CH6 完整实测边界和 CH2..CH5 四内点初值，未来内点只评分；边界的时间插值是求解输入，不是新测量。只评分 CH2..CH5，排除各段初始化首帧。

主要报告 RMSE（K 温差单位）、逐测点 RMSE、MAE、最大绝对误差；相对 L2 的分母是按固定训练参考温度中心化的实测内点，不使用摄氏绝对水平制造低百分比。保留分母退化时的空值。另报告原样初值持久预测、同实测边界的线性空间插值，以及新模型相对旧 L1 和两基线的 RMSE 改善比例，负值代表更差。5% 仅为历史描述性参照，不作为删组选优条件。

仅两条高电压条件测试，结果不足以证明一般泛化、连续物性正确或唯一 PDE。未实测环境温度，h/c 可能代偿温度参考和边界/传感器偏差。未独立校准传感器，作者图中 ±2°C 不能当作本项目误差置信区间。完成评分后这些数据即已被查看，复现不再构成新盲测。
