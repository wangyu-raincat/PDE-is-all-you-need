**Mendeley 金属热杆数据：九组固定训练与独立重复实验报告**

九组预定实验全部完成。四组的最终四内点条件预测相对 L2 误差低于预设的描述性 5% 参考线，但**这不是 PDE 发现成功率，当前尚未证明任何一组恢复了唯一真实物理方程**。三个铝组保留了全部五项，两个铜组退化为单个常数项。预先指定的首要展示组 50ss 仍保留为首要结果，其最终误差为 **RMSE 3.113328 K、相对 L2 48.816%**，不能用其他较好的组替换它来陈述整体成功。

本轮“训练”指 **CPU 上的 L1 稀疏数值回归及支持集去偏**，不是神经网络深度训练。实验没有使用 GPU 或模型 API key，没有接入华为平台，也没有自行搭建或操作物理实验装置。

**来源与实验划分。** 数据来自用户提供的 `mendeley-sbcf36976g-dataset.zip`，来源指向公开数据集 [10.17632/sbcf36976g.1](https://data.mendeley.com/datasets/sbcf36976g/1)及数据论文 [10.1016/j.dib.2021.107632](https://doi.org/10.1016/j.dib.2021.107632)。数据清单记录许可为 CC BY 4.0。本次核对了本地 ZIP 的 CRC、SHA-256 和逐 CSV 文件哈希，保留原始字节；输入包声称已核对远端哈希的内容属于提供者声明，本次未独立访问上游逐文件认证。

原 ZIP 的 SHA-256 为 `ad08f96e0273ac412830013d9db930e34414482bce4b7e1a29677f13099c8149`。测点几何通过作者版本化参考代码中的坐标字面值核对，来源记录见 [provenance_verification.json](../pde_discovery/data/mendeley_heat/provenance_verification.json)。参考代码保存为文本供核查，没有执行它来生成本次结果。

三种材料分别为不锈钢（ss）、铝（al）、铜（cu），各取 50、75、100 °C 温度试验档位。数字是温度档位，不是风速。每组第 1 次完整采集用于训练，第 2 次用于开发选模，第 3 次用于最终验证，例如 `50ss1.csv → 50ss2.csv → 50ss3.csv`。没有裁剪完整实验或按最终成绩重新分组。九组分别估计系数，不把不同材料合并为共同参数。早期作者 ATMC 仓库的 `al300test.csv` 单记录探索另存于 `artifacts/real_heat`，不进入本次九组统计。

**固定方法与最终评分。** 左侧固定为 θ_t，候选库固定为 `1, theta, theta^2, theta_x, theta_xx`。每帧六个原温升测点产生四内点差分方程，不空间上采样；SS、Al、Cu 间距分别为 0.007、0.010、0.015 m。时间单位 s，空间单位 m，θ 为高于环境温度的温升 K。

训练积分窗口预设为训练时长的 2%、5%、10%，下限为两倍训练中位采样间隔。原时间点梯形积分、RMS 列缩放、固定 L1 路径筛项后，仅在训练集去偏估计系数。未收敛、秩不足、负扩散或无法在固定预算内完成正向积分的候选按协议拒绝。开发 RMSE 在最佳值 1.05 倍以内先选项数最少者，再选开发误差最低者。完整系数先写入各组冻结文件，然后才加载第 3 次实验的温度观测。最终结果不选结构、不重估系数、不补救调参；详见 [固定协议](MENDELEY_PROTOCOL.md)。

每次预测只接收两端传感器全程实测边界，以及四内点首帧温升。后续四内点观测不进入预测器。最终指标排除边界和首帧，因此准确名称是“**给定实测边界的四内点条件预测**”。它不评估未知未来边界下的自主预测，也不等于跨材料或新工况泛化。

四组低于 5% 参考线：三个铝组和 50cu。七组优于两个简单基线；75cu、100cu 均差于同边界线性插值。九组都完成了有限数值预测，不代表九组都科学有效。不同材料的温升幅度不同，RMSE 与相对 L2 应同时阅读；本报告不将它们合成一个掩盖失败组的单一平均成功指标。

**首要展示组 50ss。** 按固定规则选出的表达式为：

\[
\theta_t = 0.0040961808 + 3.721404\times 10^{-8}\theta_{xx}.
\]

该组开发 RMSE 为 3.080029 K，最终重复实验 RMSE 为 3.113328 K。模型虽然优于两种简单基线，但 48.816% 的最终相对误差不能支撑准确恢复动力学的结论。训练积分相对残差也已达 95.334%，说明模型解释不足在训练与开发阶段已有证据。该模型保留两项，只满足“项数少于五项”的计数意义，不构成成功发现真实热传导方程。

**结构与物理目标仍未达成。** 三个铝组的条件预测误差较低，但全部五项均保留，不能称为发现简洁稀疏 PDE。其 θ 与 θ_x 训练列的余弦相似度约为 −0.9976 至 −0.9978，存在强共线性，系数可能互相补偿；低误差不能证明每项的机制归因正确。

50cu 的候选包含 `1, theta, theta_x`，没有扩散项；这不能解释为铜杆没有导热。75cu 与 100cu 分别选中 `theta_t = 0.08166547` 和 `theta_t = 0.11961767`，没有任何空间耦合，是需要明确展示的模型失效案例。其项数为一并不是比完整热方程更好的科学发现。

所有组的 θ_x 系数都不能仅凭 m/s 量纲解释为材料真实流速，差分扩散系数也不能直接当作高精度连续热物性。每帧仅六点、候选项相关、空间截断误差、测量扰动及遗漏机制均可能影响识别；本轮没有相应独立实验来量化各因素的贡献。

机器字段 `sparsity_achieved` 只表示保留项数少于五项。它与“找到正确 PDE”不同；汇总文件 `unique_physical_equation_established` 保持 `false`。不锈钢简单候选为何被选中、复杂候选的真实拒绝原因、铝和铜的辨识问题，均在 [训练与开发诊断](MENDELEY_DIAGNOSTICS.md)中逐项列出。所有最终指标与冻结哈希见 [benchmark.json](../artifacts/mendeley_heat/benchmark.json)。

**本轮可用于参赛的证据。** 已完成有原始数据来源、固定角色划分、可追溯选模和独立重复留出的端到端数值实验；系统能够保留成功的条件预测以及失败或不可解释的候选。它尚未达到“从真实实验中稳定发现简洁、唯一且物理正确的 PDE”的科学目标。后续方法改进必须重新预定评价方案；本轮已查看的最终实验不能再次当作新方法从未见过的最终测试。

在项目根目录复现全部固定实验：

```bash
python -m pde_discovery measured-benchmark --output artifacts/mendeley_heat
```

仅复现预先指定的首要组：

```bash
python -m pde_discovery measured-benchmark --case 50ss --output artifacts/mendeley_heat
```

每组输出 `frozen_model.json`、`report.json`、`trajectories.npz` 和 `validation.png`；全部组的汇总在 `benchmark.json`。本报告直接读取已保存结果整理，没有重新计算最终预测或改变算法参数。
