## 2. 作品定位（一句话）

**“增材制造材料研发实验室的沉睡测试数据 → 可溯源的热物性认知与工艺决策”**：把散落的原始测温 CSV、作者分析源码、数据论文（含装置图/测点布置图）、结果表格、实验记录卡，统一识别为数据资产并标识；半自动构建“设备—试样—测点—实验—观测—模型—验证—标准条款”本体；用“检索（知识库+图谱多跳）× 推理（物理方程识别 + LLM 推理）”双驱动回答工程师的决策问题，每个结论都能点回原始证据。

典型决策问题（演示与验收都用这些）：
1. “xp（较多孔）和 xn 两根增材杆的热扩散特性有没有可辨别差异？依据是哪些记录、哪个模型？”（跨文档多跳：杆编号→构建方向/孔隙类别[数据论文]→几何参数[作者源码]→测试 CSV→拟合模型→留出误差）
2. “这批数据能否作为工艺仿真的材料输入？还缺什么实验？”（输出缺口清单：重复工况记录、风速、标准方法对照）
3. “我们的瞬态对流法和国标闪光法测热扩散系数有什么区别，结论能不能对齐到标准？”（标准对齐）
4. “两份资料里同一根杆的直径不一致，还能用吗？”（冲突保留）
5. “把新关系写进正式本体 / 用最终验证结果再调模型”（应被拒绝或转人工审核）

原合成 PDE 六类 fixture 保留为“方法自检/对照基线”，不再作为主演示。

## 3. 目标架构

```
多模态资产(CSV/XLSX/PDF图文/源码/图片记录卡)
   └─T03 资产认知层：解析→资产卡片(asset_id/类型/来源/许可/哈希)→候选事实(带页码bbox/单元格/行号)
        └─T04 本体层：种子本体+标准术语 → 多抽取器候选 → 证据与约束校验 → 置信分层 → 人工审核队列(按信息增益排序) → 版本化增量更新
             └─T05 双驱动层：
                  检索：Nexent 知识库(向量) + BM25 + 图谱多跳 evidence_path
                  推理：heat_identify(真实热杆物性识别) / pde_identify(合成对照) + LLM 链式推理
                  决策：decision_trace(结论→证据路径→原文) + 缺口/下一实验建议
                       └─T06 Skill 三层：L1 原子工具 / L2 角色技能 / L3 工作流模板(行业配置化)
                            └─T08 Nexent v2.0 上运行（T01 兼容）
```
