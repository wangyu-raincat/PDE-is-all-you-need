# T05d 同杆五次测试联合拟合：D 能否被单独识别？（预注册实验）

## 假设
单条记录拟合时 D 与 h 相互补偿（同杆五次拟合 D–h 相关系数 xp 0.996、xn 0.959）。同一试样的材料参数 D 在五次测试中应相同，而侧面散热 h（风速、环境）与漂移项 c 可逐次不同。令五次记录**共享 D、各自估计 h_k 与 c_k**，D 可能变得可识别。

## 先冻结协议，再计算
在读取任何温度数据做本实验计算之前，写 `competition_agent/verification/joint_fit/protocol.json` 并提交（记录提交哈希）。内容至少包括：
- 对象：xn、xp、yn、yp 四根增材杆，每杆全部 5 条记录。
- 模型：θ_t = D·θ_xx − h_k·θ + c_k，k=1..5；沿用 real_heat_refined 的离散方式、边界处理（两端实测温度）、参数界限 D∈[1e-8,1e-3]、h∈[0,1]、c∈[−1,1]、尺度与多起点。
- D 剖面：以联合最优 D* 乘倍率 0.25, 0.40, 0.63, 0.80, 1.00, 1.25, 1.60, 2.50, 4.00（与 IDENTIFIABILITY_PROTOCOL 相同）；每点固定 D，重估全部 h_k、c_k。近优定义：联合训练 RMSE ≤ 剖面最优 × 1.05。
- 留一记录（LORO）：5 折，每折用 4 条记录联合估计 D，记录 5 个 D 值。
- 对照基线：同一网格对每条记录单独做 D 剖面（复用既有方法），得到单记录近优倍数。
- **判定标准（写死，不得事后修改）**：
  - 某杆“D 可识别”当且仅当：联合剖面近优点 D 最大/最小 ≤ 1.5，且 LORO 五个 D 的最大/最小 ≤ 1.3。
  - “xp 与 xn 有效 D 可辨别”当且仅当：两杆均可识别，且两杆联合 D* 之比超过两杆各自 LORO 最大/最小倍数之积。
  - 否则维持 T05b 的“证据不足”结论。
- 声明：编号 3–5 已被查看，本实验为回顾性可识别性分析，不是盲测；不产生新的留出评分。
