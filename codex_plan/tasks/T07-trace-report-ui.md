# T07 决策溯源报告页

## 目标
Nexent 对话是主交互；本地再提供一个可离线打开的决策溯源页，作为评审截图和演示的“可视化证据”。

## 步骤
1. 扩展 `competition_agent/reporting.py`：生成单文件 HTML（无外部 CDN），包含
   - 资产地图：资产卡片按模态/沉睡度分组；
   - 知识图谱视图：本体版本、节点类型着色、冲突边高亮、待审核项；
   - 决策溯源树：结论 → 规则/模型 → 图谱路径 → 原文（PDF 页截图裁剪 bbox、表格单元格、源码行），点击展开；
   - 本体构建评测图表（T04 结果）。
2. 手机宽度 390px 可读；中文字体回退。
3. Nexent 回答里输出 trace_id 与报告文件路径，便于从对话跳到证据。

## 验收标准
- 5 个决策问题各生成一页或一个锚点，所有证据链接可打开到对应原文位置。
- 浏览器冒烟测试（参考现有 `tests/browser_*_smoke.py`）。
