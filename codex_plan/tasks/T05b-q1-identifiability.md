# T05b 修订决策问题 1：加入可识别性与几何混杂

## 问题
T05 对问题 1 的结论是“xp 平均 D 4.596e-6 > xn 2.361e-6 m²/s，两均值差超过最大复测极差，可辨别”。这个判据只考虑了同杆复测波动，漏了两件仓库里已有证据的事：

1. **D 的可识别性很差。** `experiments/IDENTIFIABILITY_REPORT.md`：不锈钢三组在训练 RMSE 允许 +5% 的范围内，D 可变 2.000–3.968 倍；五块删块重拟合 D 相差 1.381–4.819 倍。xp/xn 的 D 比值约 1.95，落在这个范围内。
2. **D 和 h 一起变。** trace-1：xn1 D=2.09e-6、h=0.0150；xp1 D=5.18e-6、h=0.0302——两个参数同时约翻倍，符合 D–h 此消彼长的可识别性问题。
3. **几何混杂。** xp 直径 5.302 mm、xn 6.287 mm（作者源码第 228/238 行）。模型里的 h 是侧面散热衰减率，与直径有关；直径不同的两根杆，参数差异不能直接归因于孔隙类别。
4. 方向与常识相反（较多孔的杆热扩散更高）——不作为判据，但应提示复核。

## 修改
1. `heat_repeatability` / `heat_compare` 输出 D 与 h 两个参数的逐次值、均值、极差，以及 D/h 的样本相关系数（n=5，标注“描述性”）。
2. 新增证据项：从 IDENTIFIABILITY_REPORT.md 读取不锈钢组 D 近优剖面与删块的最大/最小倍数（带行号引文），作为 `identifiability_evidence`。
3. `decision/rules.yaml` 新增规则：若两组 D 比值 ≤ 同材料类别已记录的可识别性倍数上限，或 D 与 h 同向大幅变化，或两组几何参数不同 → 结论降级为“模型参数存在差异，但不足以判定材料热扩散性质差异”，并输出下一步：按 GB/T 22588-2008 闪光法对 xn/xp 复测（每类 ≥3 个试样），复测时记录风速与加热设定。
4. 问题 1 的最终答复要并列展示：D、h、直径、复测离散度、可识别性倍数、结论等级与下一步实验。
