# T05c 增材杆传热规律与可靠性

Q0“这批增材杆测温数据遵循什么传热规律？哪些结论可靠？”已加入六问演示首位。四根杆分别在物理先验约束的候选结构中识别方程，并用留出数据验证。四组均选中 **θ_t = D·θ_xx − h·θ + c**。θ 是相对环境温升（K）；D 表示轴向热扩散（m²/s），h 是侧面散热衰减率（s⁻¹），c 表示加热或环境漂移（K/s）。

## 四根杆分别选出了什么

| 杆 | 物理先验选择 | 开发 RMSE（K） | L1 所选项 | L1 开发 RMSE（K） | 五次复测 D–h 描述性 r |
|---|---|---:|---|---:|---:|
| xn | D+h+c | 0.66198 | 1、θ_xx | 6.3397 | 0.959 |
| xp | D+h+c | 0.27238 | θ²、θ_xx | 3.9902 | 0.996 |
| yn | D+h+c | 0.36991 | 1、θ、θ²、θ_xx | 2.3104 | 0.973 |
| yp | D+h+c | 0.30395 | θ²、θ_x、θ_xx | 2.1413 | 1.000（取三位小数） |

每根杆的编号 1 用于拟合，编号 2 用于选模。4 种预设结构 D、D+h、D+c、D+h+c 的 16 次拟合全部成功，Jacobian 均达对应参数个数。保留开发 RMSE 在合格候选最优值 1.05 倍以内的结构，优先选项数最少者，同项数取较低 RMSE。每组只有 D+h+c 进入近优集合。

无物理先验对照复用 `pde_discovery.real_experiment.select_model` 和原积分窗口、L1 路径与候选库。四组支持集各不相同，xp、yn、yp 均选入 θ²，yp 还选入 θ_x。四根杆均以物理先验三项模型的开发误差较低，且各项有明确传热解释，故演示采用物理先验结果。两种方法完成全部四杆选择后才读取已有评分并计算描述性复测相关，编号 3–5 不参与选择。

## 哪些结论可靠

- **候选族内结构与条件预测。** 四套选中参数与冻结记录匹配。给定两端实测温升和四内点初值，12 条既有留出记录的四内点相对 L2 为 1.0547%–4.2793%，每条 RMSE 都优于初值持久值及同边界线性插值。未重跑最终评分。候选明细、逐记录三种 RMSE、原文与代码行均可在 [Q0 证据树](../../competition_agent/verification/decision_v3/trace-0.json) 展开。
- **单个系数。** 同杆五次复测的 D、h 强相关。T05b 引用的旧不锈钢组三组训练诊断中，D 的近优剖面倍数为 2.000–3.968，删块倍数为 1.381–4.819。这些数据限制了将单个有效系数解释为材料物性的把握。[Q1 几何混杂与对标复测](../../competition_agent/verification/decision_v3/trace-1.json)

## 实现与验收

- `scenario_am/heat_tools.py` 为既有 `heat_identify` 增加真实候选表与近优门槛。`decision/equation.py` 汇总同一批数据的两种选择、历史评分及系数限制；`decision/__init__.py`、`rules.yaml` 接入 Q0。缺少案例来源时返回证据缺口。
- `deepseek_acceptance --decision` 依次运行 Q0–Q5，并在验收中将 Q1–Q5 的问题与完整决策字段逐项对照 v2。六问通过，6 次 DeepSeek 请求、25 次 MCP 调用，输入 4,144 token、输出 97 token，合计 4,241 token。
- 六份 trace 均从 SQLite 事件链回读并与导出文件核对。v3 的 Q1–Q5 结论、等级、缺口、下一步实验及规则均与 v2 一致。证据、模型日志、字段对照保存在 `competition_agent/verification/decision_v3/`；v1、v2 保留。
- 在主目录使用 `competition_agent/build/t02-env/Scripts/python.exe` 运行 `-X utf8 -m competition_agent.deepseek_acceptance --decision --output competition_agent/build/T05c/release --max-model-calls 6`。接入层命令 `-m unittest discover -s tests -p "test_competition*.py" -v`，139/139 通过、0 跳过。新增测试检查 L1 只读取编号 1/2、候选表可重建实际开发选择，以及缺少案例证据时不启动拟合。

- 全量回归 `-m unittest discover -s tests -v` 运行 820 项，792 通过、1 失败、25 错误、2 跳过。失败和错误的测试 ID 与主线基线一致。详见 `decision_v3/tests.json`。

## 适用范围与限制

证据支持六点离散、实测边界条件下的四内点预测。四种结构的比较不能证明连续物理方程唯一，旧不锈钢组诊断也不能直接给出增材杆系数的统计区间。L1 对照仅使用约定的五项候选库与训练、开发记录，未为 L1 新增留出评测。
