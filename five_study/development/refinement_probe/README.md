# 单次训练系数校准探针：开发预测改善，系数向量误差退化

本探针仅针对已经查看的旧 KS coarse、1% 噪声、种子97条件。不是新的留出验证，没有读取旧最终场，也没有生成正式新数据。代码与完整结果分别为 `probe.py`、`fitted.json`、`result.json`，运行日志为 `probe.log`。本目录已存在结果，脚本拒绝覆盖。

结构固定为旧 `denoised_median` 模型的 `u_xx,u_xxxx,u*u_x`。拟合函数只接收三条旧训练观测和初始系数；每条轨迹使用首个四分之一时间范围内的可用观测，共13帧，实际时间0–4.8。每次推进仅由观测首帧经过固定频谱硬阈值处理后初始化，未使用中途帧重启。

残差为完整空间网格的观测差，排除初帧；各轨迹等权，并以从带噪训练观测估计的全局RMS归一化。参数为 `c_initial*(1+delta)`，固定 `delta∈[-0.25,0.25]`；SciPy `least_squares` 使用两点有限差分、最多20次函数求值、三项终止阈值均为1e−6。没有调参搜索。参考系数只在拟合结果保存、旧开发评分结束后用于诊断。

3次优化迭代、包含有限差分共13次残差调用，在2.829秒内满足梯度终止条件；Jacobian秩3、条件数5.985，参数未触边。训练目标从 `1.5362846e−4` 降至 `1.4411449e−4`。

| 指标 | 原系数 | 校准系数 |
|---|---:|---:|
| u_xx | −1.004386380 | −0.988235516 |
| u_xxxx | −1.012669698 | −0.984710880 |
| u*u_x | −1.002308397 | −0.998713317 |
| 旧开发两轨迹平均相对L2 | 5.01528% | 3.70935% |
| 旧开发等轨迹RMSE | 0.04766082 | 0.03520751 |
| 系数向量相对误差 | 0.78547% | 1.11627% |
| 最坏真实项系数相对误差 | 1.26697% | 1.52891% |

两条开发轨迹相对误差分别从4.53947%/5.49109%降到3.39171%/4.02699%。但系数向量误差上升，并超过 `max(1.25×0.78547%,1%)=1%` 的既有逐条件回归限值。不能仅凭开发预测改善采纳该系数，也不能声称最终预测目标已经达到。该单次探针支持继续优先处理首帧噪声估计问题；不支持用预测误差补偿来替代方程系数准确性。

拟合结果在首次读取开发场前保存；训练与开发五个输入文件摘要、起始模型摘要及启动/结束核对的五个主要源码摘要均保留在JSON中。原生产模块没有修改。
