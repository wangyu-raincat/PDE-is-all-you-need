# 内部网格加密与弱形式 PDE 识别

本轮针对上一轮粗采样 KS 预测退化进行改进。保留全部旧实现；`forecast.py` 只把给定观测初帧作周期 Fourier 插值，在4倍内部空间网格推进，再回到原观测点。插值点是计算点，不是新增测量。时间积分器、物理约束、九项库、L1 路径和弱形式三个变体不变。

固定四臂比较：

| 方法 | 识别特征 | 开发选择及最终预测 |
| --- | --- | --- |
| adaptive_original | 原时间积分、自适应 L1 | 原观测网格 |
| weak_original | 上轮时空弱形式、自适应 L1 | 原观测网格 |
| adaptive_resolved | 原时间积分、自适应 L1 | 4倍内部网格 |
| weak_resolved | 上轮时空弱形式、自适应 L1 | 4倍内部网格 |

每个方法都在开发和最终阶段使用同一个预测器，不能只在最终评分时更换网格。仍以开发轨迹等权 MSE 的均值平方根选模，在最优值1.05倍加1e-12内优先少项，再比较误差/固定编号；不在不同方法之间事后回退，也不使用参考项、真实噪声方差或最终未来数据选模型。

## 证据和预定门槛

`development/DIAGNOSIS.md` 与全部72次控制记录来自已经查看的旧 KS，属于回顾性诊断。参考方程只出现在明确标记的诊断对照，生产预测接口不接受真实方程或未来场。加密空间、加密时间和先投影初帧的控制分别保留；不能把诊断结果称新验证。

正式验证保持上一轮三个数值方程族、物理参数、初值分布、网格及时间范围，只使用预定新角色种子88000–88300。每族3训练、2开发、3最终轨迹；3族×2采样×5噪声条件×4方法共120配置，360次预测共享9个最终初值，不是360次独立物理实验。无新增真实测量或未知 PDE 家族。

协议先冻结，再生成训练/开发数据；120个模型和依赖摘要全部冻结后，才生成最终初值。最终由带噪首帧推进，干净未来只评分。噪声为训练轨迹等权 RMS 的0.1%或1%，两个种子53/89；完整与粗采样、不同强度之间按固定规则配对。

主要候选为 `weak_resolved`，公平对照为使用同一预测器的 `adaptive_resolved`，另检查相对 `weak_original` 的回归。两个对照都要求无干净结构退化，完整项恢复总数不降、漏项/多余项/求解失败总数不增；每配置系数向量误差不超过 `max(1.25×对照,1%)`，预测不超过 `max(1.25×对照,5%)`。每个真实系数误差仍须在无噪及0.1%噪声时≤10%，1%噪声时≤25%。

明确收益规则在生成正式数据前写定：相对 `adaptive_resolved`，至少2个新增完整恢复且覆盖2族，**或**至少2族的“各条件最坏真实项误差”的中位数减少25%且至少1个百分点。该系数路径处理结构指标接近上限的情况，不能在看到结果后才选择阈值。两条路径之外的全部检查仍必需。绝对预测误差超过10%的数量、最坏值和分族结果另报；10%不是额外晋级门槛，不能将相对门槛通过解释成所有预测都低于10%。

## 运行

安装根目录的 `requirements-repro.txt`，使用 Python 3.12。提供源码匹配的独立校准收据，数据通过本地确定性生成器重建，无需新增外部下载。

```bash
python -m unittest discover -s tests -v
python -m resolved_study.run prepare
python -m resolved_study.run freeze --workers 3 --output resolved_study/results/reproduction
python -m resolved_study.run evaluate --output resolved_study/results/reproduction
```

已有准备、模型或部分最终场不覆盖。`first_run` 保存首轮记录；今后重新使用已评分数据改方法，应标回顾性或复现。交付省略完整观测数组和运行时准备收据，收据审计副本在结果 `provenance/` 下，避免缺少数组却误判已准备。

默认内部网格最多2048点，因此4倍加密最多接受512个观测空间点；超过预算明确拒绝，不静默降低分辨率。本方法仍限一维均匀周期标量自治常系数九项库。单校准初值的空间/步长加密检查不是每条正式轨迹的误差认证；加密也不能恢复观测初帧中本就不存在的真实高频信息。
